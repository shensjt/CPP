## 一句话

把 Web Server 从“能跑”推进到“内容更新不重启、部署可验证、慢连接不撑爆内存、可优雅停机”。

## 本版本范围

### 缓存与 HTTP

- LRU 缓存项保存 `body + mtime + size`，命中后 `stat` 比对；
- 不一致按 miss 重读，内容更新后不需要重启容器；
- 200 响应带 `ETag` / `Last-Modified` / `Cache-Control`；
- 支持 `If-None-Match`（多值、弱 ETag、`*`）和 `If-Modified-Since`；
- 304 响应不带 body，也不带 `Content-Length`。

### 请求与连接边界

- 请求限额：request line 8KB、Headers 32KB、Body 1MB；
- Body 超限返回 413，不再混为 400；
- 读缓冲上限 2MB，写缓冲上限 8MB；
- 超限直接关闭连接，避免慢客户端/大请求导致内存无界增长；
- 这是有界缓冲 + 关闭，不是完整的暂停/恢复背压。

### 可观测性

- 编译期通过 `BUILD_COMMIT` 注入 commit；
- `/healthz` 返回 `{"status":"ok","commit":"..."}`；
- `/healthz` 支持 GET/HEAD，其他方法 405，`Cache-Control: no-store`；
- 访问日志记录 method / path / status / bytes / duration；
- 400 / 413 / 500 也写访问日志；
- 日志按大小滚动，保留 5 份；
- CI docker job 和 CD 部署都校验 `/healthz` 的 commit。

### 优雅停机

- 启动前屏蔽 SIGINT / SIGTERM；
- 主线程 `sigtimedwait`，收到后停止 accept；
- 等待 worker 退出、关闭连接、刷新日志；
- `docker stop` 正常退出码 0。

### 测试

- 测试目录按 `common/`、`web_server/`、`kv_store/` 分层；
- 6 个测试可执行文件、206 个用例；
- ASan/UBSan、TSan 通过。

## 验证

- `make verify`：6/6；
- ASan：6/6；
- TSan：6/6；
- Docker 构建注入 `BUILD_COMMIT=testcommit`，容器 `/healthz` 返回 `testcommit`；
- 容器 `/` 和 `/css/style.css` 返回 200；
- 手工 SIGTERM：进程 exit 0，日志包含 `received signal 15, stopping`。

## 已知限制

- 没有域名和 TLS，直接 HTTP 8080；
- 内容发布流程（内容校验、独立发布、回滚）尚未实现；
- 只有本地访问日志，没有 metrics / 告警 / 链路追踪；
- 读写缓冲上限是简化背压，超限直接关闭慢连接；
- 没有 sendfile、限流和连接数上限；
- KV Store 功能未变，仍没有 TTL、淘汰和 AOF 重写；
- GitHub runner 到 ACR 认证端点偶发 `connection reset`，重跑 deploy job。
